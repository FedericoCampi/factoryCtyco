# Qué preparar para las próximas etapas

Se puede seguir desarrollando con modelos provisionales. Estos assets ayudan
a reemplazarlos y a darle identidad al juego; no son un requisito para continuar.

## Prioridad

1. **Montón de chatarra:** metal roto, piezas de robot y placas apiladas.
2. **Trituradora:** entrada amplia de chatarra y salida más pequeña de fragmentos.
3. **Fundición:** entrada de fragmentos y salida visible de placas metálicas.
4. **Depósito:** caja o contenedor industrial con puntos claros de conexión.
5. Después: cinta recta, curva de 90 grados, fragmento y placa metálica.

## Entrega sencilla

- Un archivo GLB por objeto, con color, materiales y texturas incluidos.
- Dejar los originales en `C:\Users\Usuario\Desktop\3D assets\GLBs`.
- Nombres sugeridos: `chatarra.glb`, `trituradora.glb`, `fundicion.glb`,
  `deposito.glb`. Avisar qué archivo corresponde a cada objeto.
- El robot mide 1,80 m; las máquinas pueden tener aproximadamente su altura
  o algo más. La escala exacta se ajustará dentro del proyecto.
- Para las máquinas, que la entrada y salida se distingan desde arriba en diagonal.
- Si hay rodillos, engranajes o tapas que deban moverse, conviene mantenerlos
  separados en el modelo. Se puede trabajar con una máquina estática al principio.

Mantener el estilo industrial del mapa: metal gris, detalles naranjas y luces
cian. Una referencia visual para cada máquina también sirve antes del modelo final.
No hace falta preparar enemigos, armas ni defensas en esta etapa.
