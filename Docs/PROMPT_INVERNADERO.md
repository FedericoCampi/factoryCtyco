# Segundo escenario: base arquitectónica para conversión a 3D

Usar una captura de la escena actual como referencia junto con este prompt:

Crear un escenario base para un videojuego 3D, respetando el estilo visual, la escala y la presentación de la imagen de referencia. Diseñar una antigua instalación botánica futurista, distinta de la fábrica industrial, con suelo gris claro, estructuras blancas desgastadas y pequeños detalles turquesa.

Mostrar únicamente la arquitectura fija: una plataforma cuadrada completa, suelo plano y continuo con paneles grandes, bordes bajos, algunos pilares estructurales y un acceso frontal corto de cuatro metros de ancho para conectar con otro escenario. Distribución abierta, con amplias superficies vacías para colocar posteriormente máquinas y elementos jugables. Sin techo, para que todo el interior sea visible.

Presentar el escenario como una única maqueta 3D aislada, vista ortográfica elevada en tres cuartos, completamente dentro del encuadre y sobre fondo gris neutro uniforme. Iluminación suave y pareja, sombras discretas, geometría sólida y formas claramente legibles. Acabado similar a un asset de videojuego preparado para reconstrucción en 3D.

No incluir robots, personajes, criaturas, máquinas, herramientas, cajas, barriles, cables sueltos, plantas, árboles, agua, terreno exterior, montañas, cielo, niebla, texto ni interfaz. Sin objetos decorativos independientes. Sin perspectiva cinematográfica ni profundidad de campo.
